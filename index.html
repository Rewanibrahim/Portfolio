A designer who can read the code

I graduated in Computer Science & Artificial Intelligence from Pharos University in Alexandria with a 3.73 CGPA, then completed Route's UI/UX Design Diploma. I start with people: interviews, surveys, affinity and empathy maps. Then I structure flows, design high-fidelity screens from a component library, and hand developers files they can build.

Because I've built front ends and back ends myself, my designs come with real states, consistent spacing and components that map to code. My goal: grow as a UI/UX designer on a product team, and keep sharpening my front-end skills alongside it.

  • 01

    Research first

    Interviews, surveys and competitive analysis before any pixel.

  • 02

    Systems, not screens

    Auto Layout, components and variants that scale across flows.

  • 03

    Built to ship

    Dev Mode-ready handoff, and hands-on Flutter, HTML, CSS and JavaScript.
