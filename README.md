# Rewan Ibrahim — Portfolio

UI/UX designer & front-end developer portfolio. Hand-coded static site (HTML, CSS, vanilla JS), no build step.

- `index.html` — page content and case studies (BloomTech, Happy Tails, Closet, TMHM)
- `styles.css` — design tokens, layout, animations (respects `prefers-reduced-motion`)
- `main.js` — hero sequence, CSS typing effect, drag-to-scroll screen strips, lightbox
- `assets/img/` — optimized WebP exports of the Figma screens

Run locally: open `index.html`, or `npx serve .`
Deploys automatically on Vercel from `main`.
